# Портфолио Дмитрия

Статический сайт для GitHub Pages. Связь с заказчиком ведёт на профиль Авито.

## Локальный запуск

Из этой папки запустить `python -m http.server 4173 --bind 127.0.0.1` и открыть `http://127.0.0.1:4173/`.
Сборка и установка зависимостей не требуются.

## Содержание

- Тексты, отзывы и ссылка Авито: `assets/content.js`.
- Главная страница: `index.html`, `assets/portfolio.css`, `assets/portfolio.js`.
- Автосервис: `demos/autoservice/`. Сервис, цены и изображения демонстрационные; форма никуда не отправляет данные.
- КЭДО: `demos/kedo/`. Используется оригинальный frontend проекта автора с его разрешения: HTML, CSS, обработчики, архив документов и карточки. `demo-api.js` заменяет серверные запросы вымышленными данными в памяти, `demo-runtime.js` задаёт режим демо, а `demo.css` удаляет брендирование и адаптирует открытый пример.

В демо КЭДО доступны главная, входящие, документы, поиск, согласование, предпросмотр демонстрационного PDF и задачи. Остальные операции требуют полной серверной версии. Все изменения демоданных сбрасываются при перезагрузке.

## Ресурсы

Onest размещён локально, лицензия SIL Open Font License находится в `assets/fonts/OFL.txt`.
Четыре иллюстрации автомастерской сгенерированы для вымышленного проекта встроенным imagegen. Изображения интерфейсов являются скриншотами работающих демонстраций.
Отзывы воспроизведены по предоставленному автором скриншоту Авито.

## Публикация

GitHub Pages публикует корень ветки `main`. Файл `.nojekyll` отключает обработку Jekyll. Все локальные ссылки используют относительные пути. Серверные конфигурации, база данных и закрытые файлы исходного проекта в сайт не входят.
